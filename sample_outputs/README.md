# Sample Outputs Guide

This folder documents the artifacts generated by `scripts/run_pipeline.py`.

## 1) `routing_metrics.csv`
**Purpose**: high-level routing KPIs from routed sample output.  
**Type**: mostly observed rates from routed records, plus estimated cost fields.  
**Generated when**: every pipeline run that produces routed tickets.

Key fields include:
- `rule_based_rate`, `ml_high_confidence_rate`, `llm_invocation_rate`, `human_fallback_rate`
- `avg_routing_confidence`
- `cost_per_ticket_usd_estimated`

## 2) `threshold_sweep.csv`
**Purpose**: policy simulation across confidence thresholds.  
**Type**: estimated rates/costs from model confidence distributions.  
**Generated when**: every pipeline run.

Contains stage-rate estimates (auto-route, LLM fallback, human fallback), estimated cost/ticket, and a recommendation score.

## 3) `routing_policy_recommendation.csv`
**Purpose**: one-row analytic policy guide from threshold sweep.  
**Type**: estimated recommendation artifact.  
**Generated when**: threshold sweep has a recommended row.

Use this as a starting point for policy review, not as a guaranteed optimum.

## 4) `eval_comparison.csv`
**Purpose**: measured summary comparison of ML vs keyword baseline.  
**Type**: measured metrics (accuracy, macro/weighted F1 and lift).  
**Generated when**: `data/eval/eval_tickets.csv` exists.

## 5) `eval_per_class_metrics.csv`
**Purpose**: per-class precision/recall/F1/support by model (`ml_tfidf_lr`, `keyword_baseline`).  
**Type**: measured eval diagnostics.  
**Generated when**: eval set is available.

## 6) `eval_confusion_matrix.csv`
**Purpose**: confusion matrix counts in long format for each model.  
**Type**: measured eval diagnostics.  
**Generated when**: eval set is available.

---

## Measured vs Estimated vs Proxy (quick reference)
- **Measured**: uses labeled eval ground truth (e.g., eval comparison and confusion matrix files).
- **Estimated**: derived from assumptions/confidence simulations (e.g., threshold sweep costs).
- **Proxy**: heuristic-derived signals where true labels are not available (e.g., complexity label logic).
